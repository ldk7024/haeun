# 하은 포트레이트 이미지 에셋

이 폴더에 반실사 포트레이트 이미지를 넣으면 자동으로 적용됩니다.

## 사용 방법

파일명: haeun-portrait.png  (또는 webp)

이미지 사양 (권장):
- 비율: 세로형 (3:4 ~ 2:3 권장)
- 해상도: 480×640 이상
- 배경: 투명 (PNG) 또는 어두운 단색

파일을 이 폴더에 복사하면
Spring Boot 정적 리소스로 /images/haeun-portrait.png 경로에서 서빙됩니다.

이미지가 없으면 기존 SVG 캐릭터가 자동으로 fallback 표시됩니다.
